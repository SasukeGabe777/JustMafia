Phone says "can't connect"? Check these

  1. Same Wi-Fi. The phone must be on the same network as this PC: not mobile data, not a "Guest" network (guest Wi-Fi usually blocks devices from seeing each other).
  2. Windows Firewall. The first time JustGameBox starts, Windows asks whether to allow it. It needs Private networks ticked. If you pressed Cancel: open the firewall page below → Change settings → find JustGameBox → tick Private → OK. JustGameBox never changes your firewall by itself.
  3. Network type is Private. If Windows thinks your home Wi-Fi is Public, it blocks phones. Settings → Network & internet → your Wi-Fi → Network profile type → Private network.
  4. VPN or other security software. Pause a VPN, or allow JustGameBox in a third-party firewall/antivirus.
  5. Type the address. On the phone's browser, type the address above exactly (it starts with http://, not https). If that page opens, scanning works too.
  6. Still stuck? Try another network adapter above, or use Online mode.
