# Claude Code project instructions

Read and follow `AGENTS.md` and `docs/COLLABORATION.md` before starting work.
They are the shared collaboration rules for Justin/Claude and Gabe/Codex.
Read `PLAN.md` and inspect the current implementation for the assigned task.
Use `claude/<short-task>` branches. Once the work is tested and integrated
with the latest `origin/main`, merge it into `main` and push. A pull request
is optional (agreed by Gabe). Never force-push. Preserve the other
contributor's work and report actual sync/test status honestly.
